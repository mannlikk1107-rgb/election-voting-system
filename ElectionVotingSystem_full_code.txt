# Database Design

PostgreSQL is managed through Prisma. `prisma/schema.prisma` defines the application contract; committed SQL migrations are used for deployment.

## Relationships

- A user may create elections, request eligibility for elections, submit nominations, vote, and perform audited actions.
- Each election owns eligibility requests, nominations, and votes.
- Eligibility and nomination reviews optionally reference the administrator who reviewed them.
- A vote references its election, voter, and an approved nomination belonging to that same election.
- Audit entries record actor, action, entity, and non-sensitive details.

## Integrity rules

- `User.email` and `User.username` are unique.
- `(VoterEligibility.electionId, userId)` prevents duplicate eligibility requests.
- `(Nomination.electionId, userId)` prevents duplicate nominations.
- `(Vote.electionId, voterId)` is a database-enforced one-vote limit, including concurrent submissions.
- A composite foreign key from `(Vote.electionId, nominationId)` prevents votes for a nomination in another election.

Indexes cover election status/time queries, review queues, and vote aggregation.

## Privacy note

The normal administrator interface reports only whether an approved voter has voted, and vote audit events do not store candidate choice. The relational vote record still contains both voter and nomination identifiers to enforce constraints; a database administrator with direct SQL access can correlate them. This prototype is not end-to-end anonymous and should not be used for high-stakes or legally binding elections.

# Deployment

## Architecture

Browser -> Render Web Service -> Neon PostgreSQL

Render hosts the Node.js/Express application. Neon provides persistent PostgreSQL independently of Render's expiring free database. The app and Prisma schema remain compatible with other PostgreSQL providers.

## Neon Configuration

1. Create a Neon project/database. In Neon **Connect**, use the pooled connection URL for the application and the direct connection URL for Prisma migrations.
2. In the Render Web Service environment settings, set `DATABASE_URL` to Neon's pooled URL and `DIRECT_URL` to Neon's direct URL. Keep both secret values in Render's protected environment settings, never in `render.yaml`, source, documentation, or Git.
3. Set `NODE_ENV=production`. `render.yaml` generates `SESSION_SECRET`; verify it is at least 64 random characters. Add `SEED_ADMIN_PASSWORD` only for a deliberate one-off seed of a dedicated demo database.

## Render Web Service

Connect the GitHub repository to Render as a Blueprint and apply `render.yaml`. The service uses:

- Build: `npm ci && npm run prisma:generate && npm run prisma:deploy`
- Start: `npm start`
- Health check: `/health`

The build applies committed migrations and never runs the seed. The server uses Render's `PORT`, binds to `0.0.0.0`, and enables `trust proxy` in production. Confirm `/health` before opening database-backed pages. Back up Neon before schema changes and review the backup/restore options available for the selected plan.

## Local Development

Follow [POSTGRESQL_SETUP.md](POSTGRESQL_SETUP.md) to configure a private `.env` for local PostgreSQL or Neon. Apply migrations only to the intended development database; seed only a disposable demo database. Start with `npm run dev` and open http://localhost:8888.

# PostgreSQL Setup

This application uses PostgreSQL for election records and production sessions. Do not substitute SQLite or test against a production database during development.

## Neon PostgreSQL with Render

1. Create a Neon project and database. In Neon's **Connect** panel, select the pooled connection string for the running application and the direct connection string for Prisma migrations.
2. In the Render Web Service environment settings, set `DATABASE_URL` to the Neon pooled URL and `DIRECT_URL` to the Neon direct URL. Use the URLs as provided by Neon, including their TLS parameters. `prisma/schema.prisma` maps `DATABASE_URL` to runtime queries and `DIRECT_URL` to migrations.
3. Set `NODE_ENV=production`. Render's Blueprint generates `SESSION_SECRET`; confirm it is at least 64 random characters.
4. Deploy. The build command runs `npm ci`, `npm run prisma:generate`, and `npm run prisma:deploy`; it applies committed migrations and does not seed demo records.
5. Confirm `/health` is healthy before opening database-backed pages.

For local development against Neon, use the Neon pooled URL for `DATABASE_URL` and the direct URL for `DIRECT_URL` in the ignored local `.env`. Prefer a local PostgreSQL instance for routine development. Never put either URL in source control, documentation, terminal output, or chat.

Do not put database URLs or seed passwords in `render.yaml`; `DATABASE_URL` and `DIRECT_URL` are `sync: false` inputs configured privately in the Render dashboard. Before a schema migration, create and verify a Neon backup using the options available for the selected plan.

## Local Windows PostgreSQL

1. Install PostgreSQL for Windows using the official PostgreSQL installer, or use an existing trusted local PostgreSQL installation. Ensure the PostgreSQL service is running and `psql` is available in PowerShell.
2. Connect to the local server as its database administrator:

   ```powershell
   psql -U postgres -h localhost
   ```

3. At the `psql` prompt, create a dedicated application role and database. Set its password interactively so it is not written into shell history:

   ```sql
   CREATE ROLE election_app LOGIN;
   \password election_app
   CREATE DATABASE election_system OWNER election_app;
   \q
   ```

4. Create an ignored `.env` file in the workspace root and set private values for `DATABASE_URL`, `DIRECT_URL`, a random `SESSION_SECRET` of at least 64 characters, and `SEED_ADMIN_PASSWORD`. For local PostgreSQL, use this URL shape:

   ```text
   postgresql://<role>:<percent-encoded-password>@localhost:5432/election_system?schema=public
   ```

   For a direct local PostgreSQL connection, both variables can use the same URL. Percent-encode reserved characters in the password. Never paste the resulting URL into a terminal command, logs, Git, or a support request.

5. Validate and apply only committed migrations, then seed the local demonstration database:

   ```powershell
   npm run prisma:validate
   npm run prisma:generate
   npm run prisma:deploy
   npm run prisma:seed
   ```

   `npm run prisma:migrate` is for creating a new development migration after a schema change; review and commit that migration before deploying it. Never run `prisma migrate reset` against a database containing data.

## Safe, Repeatable Seeding

`npm run prisma:seed` uses upserts and a stable demo-election ID. Re-running it updates the known demo accounts, election, eligibility rows, and nominations instead of adding duplicate rows. It sets the demo election to its sample voting state and rewrites those demo records; therefore, run it only against a disposable/local demo database, never against a real election database.

Set a private policy-compliant `SEED_ADMIN_PASSWORD` in the ignored local `.env` before seeding. Seeding refuses to run when the variable is missing. On Render, provide it only through a protected one-off environment/job, run the seed only against a dedicated demo database, then remove the temporary secret. Do not run the seed as part of every deploy.

The seed creates one administrator, three candidate accounts, two approved voters, one pending voter, one sample election, three approved nominations, and the corresponding voter eligibility records. All demo accounts use the configured seed password.

## Backups

Before migrations or maintenance, take a PostgreSQL custom-format backup to a protected location outside the repository. Create that secure folder first, then `pg_dump` prompts for the database password when required:

```powershell
New-Item -ItemType Directory -Force -Path C:\SecureBackups
pg_dump --format=custom --host localhost --port 5432 --username election_app --dbname election_system --file C:\SecureBackups\election_system.dump
```

Encrypt and access-control backups because they contain user and election data. Verify backups by restoring into a new, empty test database (not over the source):

```powershell
createdb -h localhost -U postgres election_system_restore
pg_restore --host localhost --username election_app --dbname election_system_restore --no-owner C:\SecureBackups\election_system.dump
```

Do not commit backup files. For Neon, use the project's supported backup/restore options and store exports outside the repository with equivalent protection.

## Troubleshooting

- **`Environment variable not found: DATABASE_URL`:** confirm the ignored local `.env` exists and contains a non-empty `DATABASE_URL`; restart the server after editing it. Do not print the URL to check it.
- **Connection refused:** confirm the PostgreSQL Windows service is running, the host/port are correct, and local port 5432 is reachable.
- **Authentication failed:** reset the dedicated local role password interactively and update the private `.env`; percent-encode reserved URL characters.
- **Prisma migration cannot connect:** run `npm run prisma:validate` first; confirm `DIRECT_URL` points to a direct PostgreSQL connection, then retry `npm run prisma:deploy`. Do not reset or drop the database to work around migration errors.
- **Render deploy fails on migration:** inspect the migration error without exposing connection strings; confirm `DIRECT_URL` is the Neon direct endpoint and the database role can create schema objects. Back up before repairing or retrying a failed migration.
- **Missing schema after deploy:** verify the committed migration directory and Render build output; `prisma migrate deploy` applies committed migrations but does not create new migration files or insert seed data.

# Requirements

## Scope

The prototype provides account registration and sign-in, administrator-managed elections, per-election voter eligibility, candidate nominations, a confidential-to-normal-UI ballot, result publication, and audit events. It is intended for local evaluation and Render deployment.

## Roles

- `VOTER`: requests election-specific approval and votes only after approval.
- `CANDIDATE`: manages approved nomination records through the candidate dashboard. New accounts start as voters; an approved nomination grants this role.
- `ADMINISTRATOR`: creates and manages elections, reviews eligibility and nominations, previews results, publishes results, and inspects audit events.

## Election lifecycle

`DRAFT -> NOMINATION -> VOTING -> CLOSED -> PUBLISHED -> ARCHIVED`

Each transition is checked server-side. Nomination and voting endpoints also compare server time with the configured phase boundaries. Voting is rejected outside the voting window regardless of the displayed status.

## Data and integrity

PostgreSQL is the source of truth. Prisma enforces unique emails/usernames, one eligibility request and nomination per election/user, and one vote per election/voter. See [DATABASE_DESIGN.md](DATABASE_DESIGN.md).

## User experience

Views are responsive EJS pages styled with Bootstrap 5. Major navigation labels include English and Traditional Chinese. User-entered text is rendered with EJS escaping.

## Operational constraints

The home and health routes do not query PostgreSQL. The app requires PostgreSQL for authentication and election operations. Sessions use PostgreSQL storage in production and Express's in-memory store only for local development/test use.

# Security Notes

## Implemented controls

- bcrypt password hashes; password hashes are never passed to templates.
- Server-side role and election-eligibility checks on protected routes.
- PostgreSQL unique constraints as the final duplicate-vote barrier.
- Session regeneration at login, session destruction at logout, secure production cookies, and PostgreSQL-backed production sessions.
- Session-bound CSRF tokens for state-changing requests, Helmet headers, request-size limits, and rate limiting.
- EJS escaping for user-provided content; audit events intentionally omit selected candidate IDs.
- Production error responses do not expose stack traces or internal exception details.

## Prototype limitations

This is not a certified, end-to-end anonymous election system. The database vote row joins voter and candidate identifiers, the application does not provide cryptographic ballot secrecy, independent recount proofs, identity-provider integration, or formal penetration testing. The demo seed has a known local-only default credential. Do not use real student records or high-stakes election results without institutional security review, privacy/legal review, threat modeling, independent testing, and a verified deployment/backup process.

# Test Plan

Run `npm test` for the automated suite. It does not require a PostgreSQL server.

## Automated coverage

- Homepage and authentication form responses, CSRF token presence, and invalid registration rejection.
- Anonymous route protection and role middleware.
- Election date ordering, transition gating, and ended-election status.
- Nomination and voting time-window boundaries.
- Result percentages, turnout, ties, and zero-vote/zero-eligibility behavior.

## Database integration checks

With a disposable local PostgreSQL database configured in `.env`, run `npm run prisma:validate`, `npm run prisma:migrate`, and `npm run prisma:seed`. Verify that a second vote for the same election/voter is rejected by the unique constraint and that a vote cannot reference a nomination from a different election.

## Manual acceptance

1. Register a voter and request eligibility for an election.
2. Sign in as administrator, approve the voter, create an election, and transition its status as time windows allow.
3. Submit and review a candidate nomination; confirm only approved candidates appear on the ballot.
4. Cast one vote; attempt a second submission and verify it is rejected.
5. Close the election, preview results as administrator, publish, then verify normal visitors can view the results.
6. Confirm the admin voter list shows participation but never candidate choice.

# User Guide

## Voters

Create an account, open Elections, and request voter approval for each election. After an administrator approves the request and voting opens, choose one approved candidate, review the selection, and submit the final ballot. The system does not offer vote changes after submission.

## Candidates

During an election's nomination window, submit a display name, biography, and manifesto from the election page. An administrator reviews the nomination. Rejected nominations can be corrected and resubmitted before the deadline. Approved candidates can see their nomination status from the candidate dashboard.

## Administrators

Create an election with ordered nomination and voting windows. Move the election through its allowed lifecycle, review voter and candidate requests, and close the election before previewing and publishing results. The voter list shows only whether a ballot was recorded, not the chosen candidate.

## Demo account

For a local seeded database, the administrator account is `admin@example.edu`; all demo accounts use the `SEED_ADMIN_PASSWORD` configured privately before seeding. Demonstration credentials must never be used with real participants.

require('dotenv').config();

const bcrypt = require('bcrypt');
const prisma = require('../src/config/database');

async function upsertUser(database, { email, username, fullName, passwordHash, role }) {
  return database.user.upsert({
    where: { email },
    update: { username, fullName, passwordHash, role, accountStatus: 'ACTIVE' },
    create: { email, username, fullName, passwordHash, role }
  });
}

async function seedDemoData(database, password) {
  if (password.length < 8 || !/[A-Z]/.test(password) || !/[a-z]/.test(password) || !/[0-9]/.test(password)) {
    throw new Error('SEED_ADMIN_PASSWORD must have 8+ characters, uppercase, lowercase, and a number.');
  }
  const passwordHash = await bcrypt.hash(password, 12);
  const upsert = (account) => upsertUser(database, { ...account, passwordHash });
  const admin = await upsert({ email: 'admin@example.edu', username: 'admin', fullName: 'Election Administrator', role: 'ADMINISTRATOR' });
  const candidateOne = await upsert({ email: 'alex@example.edu', username: 'alexchen', fullName: 'Alex Chen', role: 'CANDIDATE' });
  const candidateTwo = await upsert({ email: 'sam@example.edu', username: 'sampatel', fullName: 'Sam Patel', role: 'CANDIDATE' });

# Campus Ballot

A locally runnable university election prototype built with Node.js, Express, PostgreSQL, Prisma, EJS, Bootstrap, and server-side sessions. The prototype supports accounts, election-specific voter approval, candidate nominations, one-vote-per-election enforcement, administrator review, and published results.

## Requirements

- Node.js 20 or newer and npm
- PostgreSQL 14 or newer
- Windows PowerShell, macOS, or Linux shell

## Local setup

1. Create a PostgreSQL database named `election_system` and a local database role with access to it, or create a Neon project.
2. Create an ignored `.env` file in the workspace root. Set `DATABASE_URL`, `DIRECT_URL`, `SESSION_SECRET` (at least 64 random characters), and `SEED_ADMIN_PASSWORD` privately. For Neon, use the pooled URL for `DATABASE_URL` and direct URL for `DIRECT_URL`. Never commit `.env`.
3. Install dependencies and generate Prisma Client:

   ```sh
   npm ci
   npm run prisma:generate
   ```

4. Create/update the local schema and insert demo data:

   ```sh
   npm run prisma:migrate
   npm run prisma:seed
   ```

5. Start the server and open http://localhost:8888:

   ```sh
   npm run dev
   ```

The homepage and `/health` endpoint do not require a live database connection. Database-backed pages will need PostgreSQL.

The seed creates demonstration administrator, candidate, and voter accounts. Set `SEED_ADMIN_PASSWORD` to a private policy-compliant value in the ignored local `.env` before seeding. Demonstration credentials and records are for a disposable local database only and must never be used with real participants.

Follow [docs/POSTGRESQL_SETUP.md](docs/POSTGRESQL_SETUP.md) for local/Neon database setup and [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for Render. function report(name, passed) {

function readCsrfToken(html) {
  return html.match(/name="_csrf" value="([a-f0-9]+)"/)?.[1] || null;
}

function toCountMap(rows, key) {
  return Object.fromEntries(rows.map((row) => [row[key], row._count._all]));
}

async function getAggregateSnapshot() {
  const [users, eligibility, nominations, elections, votes] = await Promise.all([
    prisma.user.groupBy({ by: ['role'], _count: { _all: true } }),
    prisma.voterEligibility.groupBy({
      by: ['status'],
      where: { electionId },
      _count: { _all: true }
    }),
    prisma.nomination.groupBy({
      by: ['status'],
      where: { electionId },
      _count: { _all: true }
    }),
    prisma.election.count({ where: { id: electionId } }),
    prisma.vote.count({ where: { electionId } })
  ]);

  return {
    usersByRole: toCountMap(users, 'role'),
    eligibilityByStatus: toCountMap(eligibility, 'status'),
    nominationsByStatus: toCountMap(nominations, 'status'),
    electionCount: elections,
    voteCount: votes
  };
}

async function getLoginIdentifiers() {
  const [administrator, approvedEligibility, candidate] = await Promise.all([
    prisma.user.findFirst({
      where: { role: 'ADMINISTRATOR', accountStatus: 'ACTIVE' },

async function attemptLogin(identifier) {
  if (!identifier || !password) return null;
  const agent = request.agent(app);
  const loginPage = await agent.get('/login');
  const csrfToken = readCsrfToken(loginPage.text);
  if (!csrfToken) return null;

  const initialCookie = (loginPage.headers['set-cookie'] || [])
    .find((cookie) => cookie.startsWith('election.sid='))?.split(';')[0];
  const response = await agent.post('/login').type('form').send({
    _csrf: csrfToken,
    identifier,
    password
  });
  const authenticatedCookie = (response.headers['set-cookie'] || [])
    .find((cookie) => cookie.startsWith('election.sid='))?.split(';')[0];

  return { agent, response, initialCookie, authenticatedCookie };
}

async function check(name, callback) {
  try {
    report(name, await callback());
  } catch {
    report(name, false);
  }
}

async function run() {
  const [baseline, identifiers] = await Promise.all([
    getAggregateSnapshot(),
    getLoginIdentifiers()
  ]);
  const completeBaseline = baseline.usersByRole.ADMINISTRATOR >= 1
    && baseline.usersByRole.CANDIDATE >= 1
    && baseline.usersByRole.VOTER >= 1
    && baseline.eligibilityByStatus.APPROVED >= 1
    && baseline.electionCount === 1;
  report('aggregate baseline available', completeBaseline);

  const passwordPolicy = typeof password === 'string'
    && password.length >= 8
    && /[A-Z]/.test(password)
    && /[a-z]/.test(password)
    && /[0-9]/.test(password);
  report('configured seed password policy', passwordPolicy);

  const administrator = await attemptLogin(identifiers.administrator);
  report('administrator login', administrator?.response.status === 302
    && administrator.response.headers.location === '/dashboard');

  const approvedVoter = await attemptLogin(identifiers.approvedVoter);
  report('approved voter login', approvedVoter?.response.status === 302
    && approvedVoter.response.headers.location === '/dashboard');

  const candidate = await attemptLogin(identifiers.candidate);
  report('candidate login', candidate?.response.status === 302
    && candidate.response.headers.location === '/dashboard');

  const invalidLogin = await attemptLogin(`invalid-${crypto.randomUUID()}`);
  report('invalid login rejected', invalidLogin?.response.status === 302
    && invalidLogin.response.headers.location === '/login');

  report('login rotates session identifier', Boolean(
    administrator?.initialCookie
    && administrator.authenticatedCookie
    && administrator.initialCookie !== administrator.authenticatedCookie
  ));

  let logoutResponse = null;
  if (administrator?.agent) {
    const page = await administrator.agent.get('/');
    const csrfToken = readCsrfToken(page.text);
    if (csrfToken) {
      logoutResponse = await administrator.agent.post('/logout').type('form').send({ _csrf: csrfToken });
    }
  }
  report('logout destroys session', logoutResponse?.status === 302
    && (logoutResponse.headers['set-cookie'] || []).some((cookie) => cookie.includes('election.sid=;')));

  if (administrator?.agent && logoutResponse) {
    const afterLogout = await administrator.agent.get('/dashboard');
    report('destroyed session blocks protected route', afterLogout.status === 302
      && afterLogout.headers.location === '/login');
  } else {
    report('destroyed session blocks protected route', false);
  }

  const anonymous = request.agent(app);
  for (const route of ['/dashboard', '/admin', '/admin/eligibilities', '/admin/nominations', '/candidate']) {
    await check(`anonymous blocked from ${route}`, async () => {
      const response = await anonymous.get(route);
      return response.status === 302 && response.headers.location === '/login';
    });
  }

  await check('voter blocked from administrator route', async () =>
    (await approvedVoter?.agent.get('/admin'))?.status === 403);
  await check('candidate blocked from administrator route', async () =>
    (await candidate?.agent.get('/admin'))?.status === 403);

  const after = await getAggregateSnapshot();
  report('aggregate counts unchanged', JSON.stringify(baseline) === JSON.stringify(after));
}

run()
  .catch(() => {
    report('verification completed without errors', false);
  })
  .finally(async () => {
    await prisma.$disconnect().catch(() => {});

const crypto = require('crypto');
const session = require('express-session');
const connectPgSimple = require('connect-pg-simple');
const { Pool } = require('pg');

function createSessionMiddleware() {
  const production = process.env.NODE_ENV === 'production';
  if (production && !process.env.SESSION_SECRET) {
    throw new Error('SESSION_SECRET is required in production.');
  }
  if (production && process.env.SESSION_SECRET.length < 64) {
    throw new Error('SESSION_SECRET must be at least 64 characters in production.');
  }
  const settings = {
    name: 'election.sid',
    secret: process.env.SESSION_SECRET || crypto.randomBytes(32).toString('hex'),
    resave: false,
    saveUninitialized: false,
    cookie: {
      httpOnly: true,
      sameSite: 'lax',
      secure: production,
      maxAge: 1000 * 60 * 60 * 8
    }
  };

  if (production) {
    if (!process.env.DATABASE_URL) {
      throw new Error('DATABASE_URL is required for production sessions.');
    }
    const pool = new Pool({
      connectionString: process.env.DATABASE_URL,
      ssl: { rejectUnauthorized: false }
    });
    const PgStore = connectPgSimple(session);
    settings.store = new PgStore({
      pool,
      tableName: 'user_sessions',
      createTableIfMissing: true
    });
  }

  return session(settings);
}

module.exports = createSessionMiddleware;

async function register(req, res, next) {
  try {
    const user = await registerUser(req.body);
    req.session.user = user;
    req.session.flashMessage = { type: 'success', text: 'Your account is ready. Apply for voter approval for an election to vote.' };
    return res.redirect('/dashboard');
  } catch (error) {
    if (error.code === 'P2002') {
      req.session.flashMessage = { type: 'danger', text: 'That email or username is already registered.' };
      return res.redirect('/register');
    }
    if (error.status === 409) {
      req.session.flashMessage = { type: 'danger', text: error.message };
      return res.redirect('/register');
    }
    return next(error);
  }
}

async function login(req, res, next) {
  try {
    const user = await authenticateUser(req.body.identifier, req.body.password);
    if (!user) {
      req.session.flashMessage = { type: 'danger', text: 'The email/username or password is incorrect.' };
      return res.redirect('/login');
    }
    const returnTo = req.session.returnTo;
    return req.session.regenerate((error) => {
      if (error) return next(error);
      req.session.user = user;
      return req.session.save((saveError) => {
        if (saveError) return next(saveError);
        const safeReturnTo = returnTo && returnTo.startsWith('/') && !returnTo.startsWith('//')
          ? returnTo
          : '/dashboard';
        return res.redirect(safeReturnTo);
      });
    });
  } catch (error) {
    return next(error);
  }
}

function logout(req, res, next) {
  req.session.destroy((error) => {
    if (error) return next(error);
    res.clearCookie('election.sid');
    return res.redirect('/');
  });
}

async function update(req, res, next) {
  try {
    const dateError = validateElectionDates(req.body);
    if (!validationResult(req).isEmpty() || dateError) {
      req.session.flashMessage = { type: 'danger', text: dateError || validationResult(req).array()[0].msg };
      return res.redirect(`/admin/elections/${req.params.electionId}/edit`);
    }
    const election = await prisma.election.findUnique({ where: { id: req.params.electionId } });
    if (!election || election.status !== 'DRAFT') throw Object.assign(new Error('Only draft elections can be edited.'), { status: 404 });
    await prisma.election.update({
      where: { id: election.id },
      data: {
        title: req.body.title,
        description: req.body.description,
        rules: req.body.rules || '',
        nominationStart: new Date(req.body.nominationStart),
        nominationEnd: new Date(req.body.nominationEnd),
        votingStart: new Date(req.body.votingStart),
        votingEnd: new Date(req.body.votingEnd)
      }

async function applyEligibility(req, res, next) {

const prisma = require('../config/database');
const { isWithinVotingPeriod } = require('../utils/electionStatus');
const { submitVote } = require('../services/votingService');

async function ballot(req, res, next) {
  try {
    const election = await prisma.election.findUnique({
      where: { id: req.params.electionId },
      include: { nominations: { where: { status: 'APPROVED' }, orderBy: { candidateDisplayName: 'asc' } } }
    });
    if (!election) return res.status(404).render('errors/404', { title: 'Election not found' });
    if (!isWithinVotingPeriod(election)) {
      req.session.flashMessage = { type: 'warning', text: 'Voting is not open for this election.' };
      return res.redirect(`/elections/${election.id}`);
    }
    const existingVote = await prisma.vote.findUnique({
      where: { electionId_voterId: { electionId: election.id, voterId: req.session.user.id } },
      select: { submittedAt: true }
    });
    if (existingVote) {
      return res.render('voting/success', {
        title: 'Vote recorded',
        submittedAt: existingVote.submittedAt,
        receipt: req.session.voteReceipts?.[election.id] || null
      });
    }
    return res.render('voting/ballot', { title: 'Cast your vote', election });
  } catch (error) { return next(error); }
}

async function confirm(req, res, next) {
  try {
    const election = await prisma.election.findUnique({ where: { id: req.params.electionId } });
    const nomination = election && await prisma.nomination.findFirst({
      where: { id: req.body.nominationId, electionId: election.id, status: 'APPROVED' }
    });
    if (!election || !nomination || !isWithinVotingPeriod(election)) {
      req.session.flashMessage = { type: 'danger', text: 'Select an available candidate while voting is open.' };
      return res.redirect(`/elections/${req.params.electionId}/vote`);
    }
    req.session.pendingVote = { electionId: election.id, nominationId: nomination.id };
    return res.render('voting/confirm', { title: 'Confirm your vote', election, nomination });
  } catch (error) { return next(error); }
}

async function cast(req, res, next) {
  try {
    const pendingVote = req.session.pendingVote;
    if (!pendingVote || pendingVote.electionId !== req.params.electionId) {
      req.session.flashMessage = { type: 'warning', text: 'Please select a candidate first.' };
      return res.redirect(`/elections/${req.params.electionId}/vote`);
    }
    const receipt = await submitVote({
      electionId: pendingVote.electionId,
      voterId: req.session.user.id,
      nominationId: pendingVote.nominationId
    });
    delete req.session.pendingVote;
    req.session.voteReceipts = req.session.voteReceipts || {};
    req.session.voteReceipts[receipt.electionId] = receipt.receipt;
    return res.render('voting/success', { title: 'Vote recorded', submittedAt: new Date(), receipt: receipt.receipt });
  } catch (error) {
    if (error.code === 'P2002' || error.status === 409) {
      req.session.flashMessage = { type: 'warning', text: 'A vote has already been recorded for you in this election.' };
      return res.redirect(`/elections/${req.params.electionId}`);
    }
    return next(error);
  }
}

module.exports = { ballot, cast, confirm };

function requireApprovedVoter(req, res, next) {
  const electionId = req.params.electionId || req.params.id;
  if (!electionId) {
    return res.status(400).render('errors/400', { title: 'Election required' });
  }

  prisma.voterEligibility.findUnique({
    where: { electionId_userId: { electionId, userId: req.session.user.id } }

    if (!eligibility || eligibility.status !== 'APPROVED') {
      return res.status(403).render('errors/403', { title: 'Voter approval required' });
    }
    req.voterEligibility = eligibility;
    return next();
  }).catch(next);
}

const crypto = require('crypto');

const unsafeMethods = new Set(['POST', 'PUT', 'PATCH', 'DELETE']);

function csrfProtection(req, res, next) {
  if (!req.session.csrfToken) req.session.csrfToken = crypto.randomBytes(32).toString('hex');
  res.locals.csrfToken = req.session.csrfToken;
  if (!unsafeMethods.has(req.method)) return next();

  const submitted = req.get('x-csrf-token') || req.body?._csrf;
  const expected = req.session.csrfToken;
  if (typeof submitted !== 'string' || submitted.length !== expected.length
    || !crypto.timingSafeEqual(Buffer.from(submitted), Buffer.from(expected))) {
    return next(Object.assign(new Error('Your form expired. Reload the page and try again.'), { status: 403 }));
  }
  return next();
}

module.exports = csrfProtection;

function errorHandler(error, req, res, next) {
  if (res.headersSent) return next(error);
  const status = Number(error.status || error.statusCode) || 500;
  if (status >= 500) console.error(error);
  const view = status === 403 ? 'errors/403' : status === 404 ? 'errors/404' : status === 400 ? 'errors/400' : 'errors/500';
  res.status(status).render(view, {
    title: status === 403 ? 'Access denied' : status === 404 ? 'Page not found' : status === 400 ? 'Invalid request' : 'Something went wrong',
    message: process.env.NODE_ENV === 'production' && status >= 500
      ? 'Please try again later.'
      : error.message
  });
}

module.exports = { notFound, errorHandler };

const { validationResult } = require('express-validator');

function validateRequest(redirectTo) {
  return (req, res, next) => {
    const errors = validationResult(req);
    if (errors.isEmpty()) return next();
    req.session.flashMessage = {
      type: 'danger',
      text: errors.array().map((error) => error.msg).join(' ')
    };
    return res.redirect(redirectTo || req.get('referer') || '/');
  };
}

const bcrypt = require('bcrypt');
const prisma = require('../config/database');

async function registerUser({ fullName, email, username, password }) {
  const existing = await prisma.user.findFirst({
    where: { OR: [{ email: email.toLowerCase() }, { username }] },
    select: { email: true, username: true }
  });
  if (existing) {
    const field = existing.email === email.toLowerCase() ? 'email' : 'username';
    throw Object.assign(new Error(`That ${field} is already registered.`), { status: 409 });
  }
  const passwordHash = await bcrypt.hash(password, 12);
  return prisma.user.create({
    data: { fullName, email: email.toLowerCase(), username, passwordHash, role: 'VOTER' },
    select: { id: true, fullName: true, email: true, username: true, role: true, accountStatus: true }
  });
}

async function authenticateUser(identifier, password) {
  const user = await prisma.user.findFirst({
    where: { OR: [{ email: identifier.toLowerCase() }, { username: identifier }] }
  });
  if (!user || user.accountStatus !== 'ACTIVE' || !(await bcrypt.compare(password, user.passwordHash))) {
    return null;
  }
  const { passwordHash, ...safeUser } = user;
  return safeUser;
}

module.exports = { authenticateUser, registerUser };

const prisma = require('../config/database');
const { canTransitionElection } = require('../utils/electionStatus');
const { recordAudit } = require('../utils/auditLogger');

async function transitionElection(electionId, status, actorUserId) {
  const election = await prisma.election.findUnique({ where: { id: electionId } });
  if (!election) throw Object.assign(new Error('Election not found.'), { status: 404 });
  if (!canTransitionElection(election, status)) {
    throw Object.assign(new Error(`Election cannot move from ${election.status} to ${status} now.`), { status: 400 });
  }
  const updated = await prisma.election.update({
    where: { id: electionId },
    data: {
      status,
      ...(status === 'PUBLISHED' ? { resultsPublishedAt: new Date() } : {})
    }
  });
  await recordAudit({ actorUserId, action: `ELECTION_${status}`, entityType: 'Election', entityId: electionId });
  return updated;
}

module.exports = { transitionElection };

const prisma = require('../config/database');
const { calculateResults } = require('../utils/resultCalculation');

async function getElectionResults(electionId) {
  const election = await prisma.election.findUnique({ where: { id: electionId } });
  if (!election) throw Object.assign(new Error('Election not found.'), { status: 404 });
  const [nominations, voteGroups, eligibleVoterCount] = await Promise.all([
    prisma.nomination.findMany({
      where: { electionId, status: 'APPROVED' },
      orderBy: { candidateDisplayName: 'asc' },
      select: { id: true, candidateDisplayName: true }
    }),
    prisma.vote.groupBy({ by: ['nominationId'], where: { electionId }, _count: { _all: true } }),
    prisma.voterEligibility.count({ where: { electionId, status: 'APPROVED' } })
  ]);
  const voteCounts = voteGroups.map((group) => ({ nominationId: group.nominationId, count: group._count._all }));
  return calculateResults(election, nominations, voteCounts, eligibleVoterCount);
}

module.exports = { getElectionResults };

const prisma = require('../config/database');
const { isWithinVotingPeriod } = require('../utils/electionStatus');

async function submitVote({ electionId, voterId, nominationId }) {
  return prisma.$transaction(async (transaction) => {
    const election = await transaction.election.findUnique({ where: { id: electionId } });
    if (!election || !isWithinVotingPeriod(election)) {
      throw Object.assign(new Error('Voting is not open for this election.'), { status: 400 });
    }

    const [eligibility, nomination] = await Promise.all([
      transaction.voterEligibility.findUnique({
        where: { electionId_userId: { electionId, userId: voterId } }
      }),
      transaction.nomination.findFirst({
        where: { id: nominationId, electionId, status: 'APPROVED' },
        select: { id: true }
      })
    ]);
    if (!eligibility || eligibility.status !== 'APPROVED') {
      throw Object.assign(new Error('You are not approved to vote in this election.'), { status: 403 });
    }
    if (!nomination) {
      throw Object.assign(new Error('Choose an approved candidate from this election.'), { status: 400 });
    }

    try {
      await transaction.vote.create({ data: { electionId, voterId, nominationId } });
    } catch (error) {
      if (error.code === 'P2002') {
        throw Object.assign(new Error('A vote has already been recorded for you in this election.'), { status: 409 });
      }
      throw error;
    }
    await transaction.auditLog.create({
      data: {
        actorUserId: voterId,
        action: 'VOTE_SUBMITTED',
        entityType: 'Election',
        entityId: electionId
      }
    });
    return { electionId, receipt: require('crypto').randomUUID() };
  });
}

module.exports = { submitVote };

function validateElectionDates(dates) {
  const nominationStart = new Date(dates.nominationStart);
  const nominationEnd = new Date(dates.nominationEnd);
  const votingStart = new Date(dates.votingStart);
  const votingEnd = new Date(dates.votingEnd);

  if ([nominationStart, nominationEnd, votingStart, votingEnd].some((date) => Number.isNaN(date.getTime()))) {
    return 'Enter valid dates for all election periods.';
  }
  if (nominationStart >= nominationEnd) return 'Nomination start must be before nomination end.';
  if (nominationEnd > votingStart) return 'Nomination must end before or when voting starts.';
  if (votingStart >= votingEnd) return 'Voting start must be before voting end.';
  return null;
}

module.exports = { validateElectionDates };

const transitions = {
  DRAFT: ['NOMINATION'],
  NOMINATION: ['VOTING'],
  VOTING: ['CLOSED'],
  CLOSED: ['PUBLISHED'],
  PUBLISHED: ['ARCHIVED'],
  ARCHIVED: []
};

function getElectionStatus(election, now = new Date()) {
  if (election.status === 'ARCHIVED' || election.status === 'PUBLISHED' || election.status === 'CLOSED') {
    return election.status;
  }
  if (election.status === 'VOTING' && now > new Date(election.votingEnd)) return 'CLOSED';
  if (election.status === 'NOMINATION' && now > new Date(election.nominationEnd)) return 'NOMINATION';
  return election.status;
}

function canTransitionElection(election, nextStatus, now = new Date()) {
  if (!transitions[election.status]?.includes(nextStatus)) return false;
  if (nextStatus === 'NOMINATION') {
    return now >= new Date(election.nominationStart) && now <= new Date(election.nominationEnd);
  }
  if (nextStatus === 'VOTING') {
    return now >= new Date(election.votingStart) && now <= new Date(election.votingEnd);
  }
  return true;
}

function isWithinVotingPeriod(election, now = new Date()) {
  return election.status === 'VOTING'
    && now >= new Date(election.votingStart)
    && now <= new Date(election.votingEnd);
}

function isWithinNominationPeriod(election, now = new Date()) {
  return election.status === 'NOMINATION'
    && now >= new Date(election.nominationStart)
    && now <= new Date(election.nominationEnd);
}

module.exports = { canTransitionElection, getElectionStatus, isWithinNominationPeriod, isWithinVotingPeriod };

function calculateResults(election, nominations, voteCounts, eligibleVoterCount) {
  const totalVotes = voteCounts.reduce((sum, item) => sum + item.count, 0);
  const candidates = nominations.map((nomination) => {
    const votes = voteCounts.find((item) => item.nominationId === nomination.id)?.count || 0;
    return {
      id: nomination.id,
      candidateDisplayName: nomination.candidateDisplayName,
      votes,
      percentage: totalVotes ? (votes / totalVotes) * 100 : 0
    };
  });
  const highest = Math.max(0, ...candidates.map((candidate) => candidate.votes));
  const winners = highest > 0 ? candidates.filter((candidate) => candidate.votes === highest) : [];
  const eligible = Number(eligibleVoterCount) || 0;

  return {
    election,
    candidates,
    totalVotes,
    eligibleVoterCount: eligible,
    turnoutPercentage: eligible ? (totalVotes / eligible) * 100 : 0,
    winners,
    isTie: winners.length > 1
  };
}

module.exports = { calculateResults };

const { validateElectionDates } = require('../src/utils/dateValidation');
const { canTransitionElection, getElectionStatus } = require('../src/utils/electionStatus');
const { Prisma } = require('@prisma/client');

const dates = {
  nominationStart: '2026-10-01T09:00:00Z',
  nominationEnd: '2026-10-10T09:00:00Z',
  votingStart: '2026-10-10T09:00:00Z',
  votingEnd: '2026-10-20T09:00:00Z'
};

describe('election timing and transitions', () => {
  test('generated schema exposes app relation names and uniqueness barriers', () => {
    const models = new Map(Prisma.dmmf.datamodel.models.map((model) => [model.name, model]));
    const relationNames = models.get('Election').fields.map((field) => field.name);
    expect(relationNames).toContain('nominations');

    const uniqueScalars = (modelName) => models.get(modelName).fields.filter((field) => field.isUnique).map((field) => field.name);
    const uniquePairs = (modelName) => models.get(modelName).uniqueFields.map((fields) => fields.join(':'));
    expect(uniqueScalars('User')).toEqual(expect.arrayContaining(['email', 'username']));
    expect(uniquePairs('VoterEligibility')).toContain('electionId:userId');
    expect(uniquePairs('Nomination')).toContain('electionId:userId');
    expect(uniquePairs('Vote')).toContain('electionId:voterId');
  });

  test('accepts correctly ordered dates and permits adjacent phases', () => {
    expect(validateElectionDates(dates)).toBeNull();
  });

  test('rejects nomination or voting windows in the wrong order', () => {
    expect(validateElectionDates({ ...dates, nominationEnd: '2026-10-11T09:00:00Z' })).toMatch(/Nomination must end/);
    expect(validateElectionDates({ ...dates, votingEnd: dates.votingStart })).toMatch(/Voting start/);
  });

  test('allows only valid, time-gated status changes', () => {
    const election = { status: 'DRAFT', nominationStart: dates.nominationStart, nominationEnd: dates.nominationEnd };
    expect(canTransitionElection(election, 'NOMINATION', new Date('2026-10-02T00:00:00Z'))).toBe(true);
    expect(canTransitionElection(election, 'VOTING', new Date('2026-10-02T00:00:00Z'))).toBe(false);
    expect(canTransitionElection(election, 'NOMINATION', new Date('2026-09-30T00:00:00Z'))).toBe(false);
  });

  test('reports an ended voting election as closed', () => {
    expect(getElectionStatus({ status: 'VOTING', votingEnd: dates.votingEnd }, new Date('2026-10-21T00:00:00Z'))).toBe('CLOSED');
  });
});

jest.mock('bcrypt', () => ({ hash: jest.fn().mockResolvedValue('bcrypt-hash') }));

const { getSeedPassword, seedDemoData } = require('../prisma/seed');

function createDatabase() {
  const store = {
    users: new Map(),
    elections: new Map(),
    eligibilities: new Map(),
    nominations: new Map()
  };
  let nextId = 1;

  return {
    store,
    user: {
      upsert: jest.fn(async ({ where, create, update }) => {
        const existing = store.users.get(where.email);
        if (existing) Object.assign(existing, update);
        else store.users.set(where.email, { id: `user-${nextId++}`, ...create });
        return { ...store.users.get(where.email) };
      })
    },
    election: {
      upsert: jest.fn(async ({ where, create, update }) => {
        const existing = store.elections.get(where.id);
        if (existing) Object.assign(existing, update);
        else store.elections.set(where.id, { ...create });
        return { ...store.elections.get(where.id) };
      })
    },
    voterEligibility: {
      upsert: jest.fn(async ({ where, create, update }) => {
        const key = `${where.electionId_userId.electionId}:${where.electionId_userId.userId}`;
        const existing = store.eligibilities.get(key);
        if (existing) Object.assign(existing, update);
        else store.eligibilities.set(key, { id: `eligibility-${nextId++}`, ...create });
        return { ...store.eligibilities.get(key) };
      })
    },
    nomination: {
      upsert: jest.fn(async ({ where, create, update }) => {
        const key = `${where.electionId_userId.electionId}:${where.electionId_userId.userId}`;
        const existing = store.nominations.get(key);
        if (existing) Object.assign(existing, update);
        else store.nominations.set(key, { id: `nomination-${nextId++}`, ...create });
        return { ...store.nominations.get(key) };
      })
    }
  };
}

describe('repeatable demonstration seed', () => {
  test('creates the expected roles and eligibility records and remains idempotent', async () => {
    const database = createDatabase();

const { isWithinVotingPeriod } = require('../src/utils/electionStatus');
jest.mock('../src/config/database', () => ({ $transaction: jest.fn() }));
const prisma = require('../src/config/database');
const { submitVote } = require('../src/services/votingService');

function createTransaction(overrides = {}) {
  const now = new Date();
  return {
    election: { findUnique: jest.fn().mockResolvedValue({
      id: 'election-1', status: 'VOTING',
      votingStart: new Date(now.getTime() - 60_000), votingEnd: new Date(now.getTime() + 60_000)
    }) },
    voterEligibility: { findUnique: jest.fn().mockResolvedValue({ status: 'APPROVED' }) },
    nomination: { findFirst: jest.fn().mockResolvedValue({ id: 'nom-1' }) },
    vote: { create: jest.fn().mockResolvedValue({ id: 'vote-1' }) },
    auditLog: { create: jest.fn().mockResolvedValue({ id: 'audit-1' }) },
    ...overrides
  };
}

describe('voting window', () => {
  const election = {
    status: 'VOTING',
    votingStart: new Date('2026-10-01T09:00:00Z'),
    votingEnd: new Date('2026-10-10T09:00:00Z')
  };

  test('accepts a vote during the election voting window', () => {
    expect(isWithinVotingPeriod(election, new Date('2026-10-05T09:00:00Z'))).toBe(true);
  });

  test('rejects votes before opening, after closing, and outside the voting state', () => {
    expect(isWithinVotingPeriod(election, new Date('2026-10-01T08:59:59Z'))).toBe(false);
    expect(isWithinVotingPeriod(election, new Date('2026-10-10T09:00:01Z'))).toBe(false);
    expect(isWithinVotingPeriod({ ...election, status: 'CLOSED' }, new Date('2026-10-05T09:00:00Z'))).toBe(false);
  });

  test('records an approved matching candidate in one transaction without logging the choice', async () => {
    const transaction = createTransaction();
    prisma.$transaction.mockImplementation((callback) => callback(transaction));
    const result = await submitVote({ electionId: 'election-1', voterId: 'voter-1', nominationId: 'nom-1' });

    expect(prisma.$transaction).toHaveBeenCalledTimes(1);
    expect(transaction.nomination.findFirst).toHaveBeenCalledWith(expect.objectContaining({
      where: { id: 'nom-1', electionId: 'election-1', status: 'APPROVED' }
    }));
    expect(transaction.vote.create).toHaveBeenCalledWith({
      data: { electionId: 'election-1', voterId: 'voter-1', nominationId: 'nom-1' }
    });
    expect(transaction.auditLog.create.mock.calls[0][0].data).not.toHaveProperty('nominationId');
    expect(result.receipt).toEqual(expect.any(String));
  });

  test('rejects a nomination that does not belong to the election', async () => {
    const transaction = createTransaction({
      nomination: { findFirst: jest.fn().mockResolvedValue(null) }
    });
    prisma.$transaction.mockImplementation((callback) => callback(transaction));
    await expect(submitVote({ electionId: 'election-1', voterId: 'voter-1', nominationId: 'nom-other' }))
      .rejects.toMatchObject({ status: 400 });
    expect(transaction.vote.create).not.toHaveBeenCalled();
  });

  test('translates a database uniqueness error to a duplicate-vote response', async () => {
    const transaction = createTransaction({
      vote: { create: jest.fn().mockRejectedValue({ code: 'P2002' }) }
    });
    prisma.$transaction.mockImplementation((callback) => callback(transaction));
    await expect(submitVote({ electionId: 'election-1', voterId: 'voter-1', nominationId: 'nom-1' }))
      .rejects.toMatchObject({ status: 409, message: expect.stringMatching(/already been recorded/) });
  });
});
